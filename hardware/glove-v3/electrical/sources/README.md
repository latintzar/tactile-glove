# Primary pin and ADC sources

- `tlv755p.pdf`: TI TLV755P Rev D, pp. 2–3. DBV SOT-23-5: pin 1 IN, 2 GND, 3 EN, 4 NC, 5 OUT.
- `mcp1501.pdf`: Microchip MCP1501 Rev F, pp. 1 and 3. SOIC-8: pin 1 VDD, 2/4/5/6 GND, 3 SHDN, 7 OUT, 8 FEEDBACK.
- `opa320.pdf`: TI OPA320 Rev F, p. 3. DBV SOT-23-5: pin 1 OUT, 2 V−, 3 +IN, 4 −IN, 5 V+.
- `mcp33131.pdf`: Microchip MCP33131D Rev B, pin table pp. 4–5; input electrical table p. 11. Pins 1 VREF, 2 AVDD, 3 AIN+, 4 AIN−, 5 GND, 6 CNVST, 7 SDO, 8 SCLK, 9 SDI, 10 DVIO. Differential input common-mode range is 0 to VREF, typical VREF/2.
- `cd74hc4052.pdf`: TI SCHS122O Rev O, pp. 3–4. CD74HC4052B SOIC pin map is recorded in `components.json`.

These files document a candidate prototype readout. Routed CAD, exact supplier suffix verification, and bench validation remain open.
