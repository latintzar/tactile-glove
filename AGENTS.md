# Artisan Glove

Start with README.md, docs/product-tour.md, docs/status.md and docs/module-map.md. The default first result is a local static engineering viewer: `python3 tools/serve.py`. Host checks and pinned tools are in docs/setup.md.

Keep product concept, source/native checks, earlier physical Bela experiments and V4 assembled-device measurements distinct. The current canonical main board has 20 remaining unconnected items; dated proposal receipts keep their historical stage. Preserve native/hash/manufacturing evidence and third-party notices. A code change needs relevant native/protocol/driver checks; a board/geometry change needs updated real design/export/clearance evidence.

Use your own development environment and credentials. Provider/customer/account data and raw private archives stay outside this repository. Device programming, physical purchases and manufacturing are deliberate actions separate from local compile/test/viewer commands.
